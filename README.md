# Tamamen Gereksiz Tamam Kanka Jeneratörü

![Logo](https://via.placeholder.com/800x200.png?text=TAMAM+KANKA+DEVİRİMİ)

## ⚠️ UYARI: Bu Proje Son Derece Ciddidir

Bu repository, insan iletişiminin temel taşı olan **"Tamam kanka"** ifadesini sonsuz varyasyonlarla üreten dünyanın ilk ve tek endüstriyel düzeydeki sistemidir. Yıllar süren araştırmalar, binlerce "kanka" ile yapılan anketler ve sayısız başarısız deneme sonucunda ortaya çıkmıştır.

### Neden Bu Proje Var?

Çünkü hayat zaten yeterince karmaşık. Birine "tamam" demek için saniyeler harcamak yerine, bu sistem sizin yerinize sürekli "Tamam kanka" üretir. Böylece siz de daha önemli işlerle (hiçbir şey yapmamak gibi) ilgilenirsiniz.

### Özellikler

- ✅ Gerçekten çalışır
- ✅ Sonsuz döngü (ta ki Ctrl+C yapana kadar)
- ✅ Rastgele varyasyonlar ve emojiler
- ✅ Aşırı ciddi görünür ama aslında tamamen gereksizdir
- ✅ Hiçbir dış bağımlılık gerektirmez (Python yeter)

### Kurulum ve Kullanım

```bash
git clone https://github.com/Tentivory/tamamen-gereksiz-tamam-kanka-jeneratoru.git
cd tamamen-gereksiz-tamam-kanka-jeneratoru
python3 tamam_kanka.py
```

Sistem başladığında durdurmak için `Ctrl+C` yapın. Durdurduğunuzda bile "Tamam kanka" diyecektir. Bu bir özelliktir, bug değil.
